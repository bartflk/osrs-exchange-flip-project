# PostgreSQL Schemas

## items

```sql
CREATE TABLE items (
 id SERIAL PRIMARY KEY,
 item_id INTEGER UNIQUE,
 name TEXT,
 category TEXT,
 buy_limit INTEGER,
 release_date TIMESTAMP
);
```

---

## prices

```sql
CREATE TABLE prices (
 id BIGSERIAL PRIMARY KEY,
 item_id INTEGER,
 timestamp TIMESTAMP,
 price BIGINT,
 volume BIGINT
);
```

---

## attention_events

```sql
CREATE TABLE attention_events (
 id BIGSERIAL PRIMARY KEY,
 source TEXT,
 item_id INTEGER,
 timestamp TIMESTAMP,
 score FLOAT,
 content TEXT
);
```

---

## updates

```sql
CREATE TABLE updates (
 id BIGSERIAL PRIMARY KEY,
 title TEXT,
 content TEXT,
 published_at TIMESTAMP
);
```

---

## recommendations

```sql
CREATE TABLE recommendations (
 id BIGSERIAL PRIMARY KEY,
 item_id INTEGER,
 generated_at TIMESTAMP,
 confidence FLOAT,
 expected_return FLOAT,
 rationale TEXT
);
```

# Final Engineering Principle

Never trust:

* LLM output
* Social sentiment
* Intuition
* Single signals

Always trust:

* Historical validation
* Backtesting
* Multiple independent signals
* Measured performance

The platform's competitive advantage is not AI.

The competitive advantage is the continuously growing dataset of OSRS events, attention, market reactions, and validated predictive signals.
